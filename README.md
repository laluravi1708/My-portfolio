# Lavanya R Portfolio
A professional responsive full-stack portfolio using HTML, CSS, JavaScript, Express and MongoDB.

## Run
1. Open in VS Code.
2. Run `npm install`
3. Copy `.env.example` to `.env` and add your MongoDB Atlas connection string.
4. Run `npm start`
5. Visit `http://localhost:5000`

The contact form stores messages in MongoDB and projects can be loaded from `/api/projects`.
